# Interactive Time Series Chart

Фронтенд-страница с интерактивным графиком. Бэкенда нет: на графике показываются статичные примерные данные из `src/data/exampleData.ts`.

![Демо графика](docs/demo.gif)

Стек: React, TypeScript, Vite, Highcharts.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте адрес из терминала — обычно `http://localhost:5173`.
